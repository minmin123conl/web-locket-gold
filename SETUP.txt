LOCKet GOLD · STATUS LAB SETUP
==============================

1. Cài dependency
   python -m venv .venv
   . .venv/bin/activate
   pip install -r requirements.txt

2. Chạy app
   python web_app.py
   Mở http://127.0.0.1:5000

3. Chế độ mặc định
   App chạy local/demo và không gọi mạng. Nhập UID 28 ký tự hoặc link hồ sơ
   hợp lệ để tạo báo cáo kiểm tra tại output/guide.txt.

4. Endpoint kiểm thử (tuỳ chọn)
   Chỉ dùng endpoint do bạn sở hữu:
   ENABLE_REMOTE_STATUS=1 FAKE_RC_URL=https://example.test python web_app.py
   App chỉ đọc GET /v1/subscribers/<uid>. Không có thao tác ghi tài khoản.

5. Kiểm tra
   python -m py_compile web_app.py
   node --check static/app.js
   curl http://127.0.0.1:5000/healthz

locketgold_novpn.mobileconfig là profile demo rỗng, không chứa CA, DNS, VPN hoặc
proxy. Nó không được dùng để thay đổi cấu hình mạng hay can thiệp dịch vụ khác.
